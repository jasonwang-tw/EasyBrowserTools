# OCR 辨識結果翻譯

## 使用者確認（2026-11-18）

1. 辨識後手動按「翻譯」，不自動傳送辨識文字。
2. 預設繁體中文，提供更多目標語言選單。
3. 譯文顯示在原文下方，在目前編輯彈窗對照。
4. 保留剪貼簿；只有按「複製譯文」才複製譯文。既有 OCR 自動複製原文行為保留。
5. 翻譯目前 OCR 結果框的全部文字，包含手動修改；不是只翻反白範圍。沿用現有 Google 翻譯，只傳文字、不傳圖片。

## 介面設定

- 沿用已確認的 daisyUI、暖黃色、既有字體與 reduced-motion。只新增目標語言 select、「翻譯」btn、原文下方的譯文 textarea、狀態及「複製譯文」btn，不重排標註或去背工具，不增加頁籤／彈窗。
- 目標語言第一版：繁中、簡中、英文、日文、韓文、德文、法文、西班牙文、義大利文、葡萄牙文、越南文、泰文、印尼文、俄文、阿拉伯文。來源語言由服務偵測；原有網頁選取翻譯的中英方向保持不變。
- 譯文唯讀，可選取；成功後才啟用複製。進行中顯示分段進度，不自動捲動或長動畫，錯誤保留 OCR 原文。

## 資料與請求

- 按翻譯時擷取當下完整結果框；上限 30,000 個 UTF-16 字元，超限清楚提示，不截斷。長文依 URL 編碼預算分段，保留 Unicode 及內部空白／換行，逐段翻譯，全部成功後才顯示。
- 背景服務限定自己編輯頁的專用 Port，固定既有 Google HTTPS 端點、語言白名單、不帶 Cookie。每段逾時 15 秒、整體 90 秒，不保存辨識文字／譯文／歷史，不增加來源權限或遠端程式。
- 原文編輯、重新 OCR、匯入新圖、切換語言或關閉視窗時中止 Port／網路並丟棄過期結果。修改不會自動重翻；再次手動點翻譯。
- 圖片、標註、去背結果與模型快取不改；文字翻譯需要網路，不屬本機 OCR／去背的離線範圍。

## 驗收

先測語言驗證、分段不漏字、錯誤／取消及舊選取翻譯相容；再於隔離 Edge 以實際 OCR 圖片測手動觸發、更多語言、原文編輯、過期回覆、斷網、剪貼簿、深淺色／320px。不自動操作日常瀏覽器、不提交或推送；完成後更新 README、PRIVACY、VALIDATION、UI_INVENTORY 與版本。

1.6.0 已完成上述功能。24 項隔離 Edge 操作與 112 項 Node 測試通過，實際 Google 繁中／日文翻譯驗證成功；長文及延遲採服務替身確認分段與取消，不宣稱所有語言品質已驗收。完整證據、套件及未驗證界線統一在根目錄 VALIDATION.md。
