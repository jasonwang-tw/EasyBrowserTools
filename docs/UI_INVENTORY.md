# 頁匣 PageKit UI 設定與盤點

1.8.2 貼上圖片：使用者要求在編輯彈窗以 Ctrl+V 取代目前截圖；空白編輯器也可貼上。使用 paste 事件中的第一張圖片，與檔案匯入共用格式／30 MB／像素驗證、狀態清理及自動 OCR。驗證完成才替換，成功清除舊標註、裁切、去背與辨識／譯文；不保留跨圖片復原。文字輸入框／contenteditable 與其他模態 dialog 不攔截；純文字或只有 HTML 圖片網址不匯入、不下載遠端圖片。處理中提示稍後再貼，不排隊覆蓋。沿用現有 daisyUI，只增補操作說明；不新增 clipboardRead、不背景輪詢剪貼簿。

1.8.1 刪除警示色：使用者明確要求刪除按鈕改紅色。沿用 daisyUI `btn-error`，模型刪除保留 outline、標註刪除保留 ghost；文字與模型按鈕邊框採既定主題 error 紅色，hover／按下以紅色淡底回饋。停用狀態維持既有透明度及不可操作規則，不改其他按鈕、模型刪除或標註操作邏輯。[官方按鈕樣式](https://daisyui.com/components/button/)。

1.8.0 裁切：使用者確認的五項回答、Cropper.js／Filerobot 比較、七平台尺寸、形狀與可編輯歷史，集中於 [CROPPING.md](CROPPING.md)。沿用既定 daisyUI 與主題；選區拖曳即時回應，dialog 不做幾何縮放轉場，避免量測期間改變座標。只有透明度短過渡，遵守減動效設定。

1.8.0 樣式收合（使用者五項回答已確認）：共用單一「樣式 ▾」入口，顏色、粗細及字級全部移入按鈕下方小浮層；收合入口保留色塊與目前工具的粗細／文字字級。切換工具不自動開啟。點外部或 Esc 收起，拖動拉桿與調整設定不自動收起。沿用既定 daisyUI 5.8.1、暖黃、深淺色與短微互動；GitHub／官方 [dropdown](https://daisyui.com/components/dropdown/) 提供原生 Popover API 方式，可置於 top layer 避免被畫布裁切。以非模態 dialog 表單承載 range／select／color，不冒充僅能選項的 ARIA menu。保持控制項 ID、工具分組記憶、筆畫／指標同步與目前功能；顏色所有工具可用、粗細只在筆畫工具、字級只在文字工具。浮層不進行焦點循環鎖定，不攔截整個工作區；支援鍵盤開啟、Esc 返回入口、Tab 離開收起、窄視窗定位與 resize 跟隨。浮層開啟時全域標註快捷鍵不操作背後畫布；忙碌、換圖、切工具與關閉視窗須收起並清理。

1.7.1 直線工具：使用者明確要求新增可畫 180°／90°／45° 的直線。沿用既定 daisyUI btn、Lucide 線段圖示（[minus](https://github.com/lucide-icons/lucide/blob/main/icons/minus.svg)）、色彩／字體／動效，不另選 UI Kit 或變更風格。於畫筆旁新增「直線」；直接拖曳，預覽與放開端點皆吸附最近 45° 倍數（含水平／垂直及反向八方向），不需 Shift。端點投影到吸附方向、沿相同方向限縮於原圖邊界，不能因逐軸裁切破壞 45°。共用一般線寬 1–30px 與目前顏色，保持原圖座標、復原／重做及 PNG／剪貼簿匯出；不加箭頭、額外彈窗或動畫。只點一下／不足 1 CSS px 的線不建立標註，Esc／pointercancel 取消預覽。其他工具角度與操作不變。驗收包含八方向、靠邊界、縮放、筆寬／顏色、取消、復原／重做及原圖隔離；保留既有色票／OCR／去背。

1.7.0 增補：使用者已完成色票五項問答並確認預設 5 色（可選 3／5／8／12）；新增同頁色票分析 dialog 與 daisyUI range 粗細拉桿。問答、選型、來源隔離、筆寬與驗收規格集中在 [PALETTE_ANALYSIS.md](PALETTE_ANALYSIS.md)。此規格取代 1.6.2 的離散線寬及固定 20px 螢光筆，保留其空心圓指標計算方式。

更新：2026-11-18，1.4.1。規範限制見根目錄 AGENTS.md；驗證證據與未驗證範圍見 VALIDATION.md。

1.5.0 增補：本機圖片匯入、去背模型管理、自動去背／取消／還原及透明棋盤預覽；問答、技術選型與驗收集中在 [BACKGROUND_REMOVAL.md](BACKGROUND_REMOVAL.md)。新工具皆沿用 btn／badge／collapse／progress，保持既定配色、字體及減動效設定；本輪另驗證深色、390／320px 無水平溢出。本機檔案選擇視窗仍屬瀏覽器原生介面。以下 1.4.1 歷史盤點不改寫成 1.5.0 全部重測。

1.6.0 增補：原文下方加入手動翻譯、十五種語言 select、唯讀譯文 textarea、獨立狀態與「複製譯文」btn。問答及資料規格集中在 [OCR_TRANSLATION.md](OCR_TRANSLATION.md)，沿用既定配色／字體與系統減動效，不另開彈窗或頁籤。文字翻譯需網路，頁尾將本機標示限定為「OCR／去背在本機」。深淺色、390／320px 與實際原文／譯文對照已驗證；確切測試範圍統一在 VALIDATION.md。

## 1.6.1 集中模型與服務管理（使用者已確認）

- 使用者已選定前述集中方案，要求保留目前功能與 daisyUI；沿用既有框架、配色、字體及動畫，不重新選風格或重複既有問答。
- 頁首只提供一個「模型與服務管理」入口，開啟同頁 daisyUI modal／原生 dialog，不新增頁籤或瀏覽器視窗。移除圖片區的去背管理折疊及右側 OCR 管理折疊，原有操作、選單與結果區保留。
- 管理內列四項：內建 OCR（已內建、免下載）、加強 OCR（31.2 MB，狀態／下載／取消／刪除）、去背模型（101.1 MB，狀態／下載／取消／刪除）、Google 翻譯（線上服務、需連網、無須安裝）。不得把 Google 翻譯誤標為本機模型，亦不顯示未檢測的「已連線」。
- 控制項只搬移 DOM，保留 ID、Port、快取鍵、大小／雜湊驗證與選用權限。缺模型時開啟統一管理並聚焦對應下載按鈕；已下載的模型沿用，不觸發重下載。
- 關閉管理不取消下載，頁首顯示「下載中」狀態，重新開啟可查看進度；取消仍用原有明確按鈕。關閉編輯視窗維持原有中止規則。
- 原生 dialog 管理模態與 Esc，補齊開啟後焦點、Tab 首尾循環與關閉後返回焦點；關閉鈕／點背景均可關閉。管理開啟時，標註 Delete／Ctrl+Z／Esc 快捷鍵不得影響背後畫布。短淡入與 reduced-motion 沿用現有設定。
- 驗收包含單一入口／四項分類、深淺色／320px、鍵盤焦點／關閉、缺模型導引、下載進度／取消／失敗／狀態、模型刪除隔離，並回歸 OCR／翻譯／去背／標註。不更動日常安裝，不提交或推送。

## 共用實作與測試界線

- 編輯頁直接載入 `vendor/ui/daisyui.css`、`ocr/ui-theme.css`。網頁工具透過 `GET_UI_KIT` 由背景讀取固定三份本機 CSS，再加入隔離的 Shadow DOM；不增加權限、web_accessible_resources、CDN 或遠端 UI 程式。讀取失敗保留原有內嵌備援樣式並允許下次重試。
- 所有自訂表單與按鈕使用對應 daisyUI 元件；模型、圖片、OCR 執行方式及快取識別不改。
- 本輪隔離 Edge：28 項編輯器＋22 項網頁工具檢查，共 50 項。宿主測試頁刻意使用 42px 字體與 20px 紅框，確認 Shadow DOM 按鈕仍正常。
- 原生 Chrome／Edge 介面、所有網站相容性、輔助技術完整稽核、首次授權允許提示及日常瀏覽器重新載入，不在已完成宣稱內。
