# 色票分析與粗細拉桿（1.7.0）

## 使用者確認（2026-11-18）

- 手動點「色票分析」才執行；預設 5 色，可切換 3／5／8／12 色。
- 顯示色塊、HEX、RGB 與約略占比；點色塊直接複製 HEX，沒有自動覆寫剪貼簿。
- 使用原始截圖／匯入圖片，不包含標註、去背結果或滑鼠覆層。
- 同一編輯視窗內的色票分析 dialog，不新增頁籤；保留 OCR、翻譯與標註。
- 粗細改為拉桿：畫筆／矩形／箭頭 1–30 CSS px（預設 3），螢光筆 8–60 CSS px（預設 20），step 1。兩組各自記住本次編輯視窗的值；換圖保留，關閉後不持久化。文字／編號不顯示無作用的粗細控制。
- 空心圓與實際筆寬同步；已完成的筆畫不隨拉桿變動，繪製中以起筆筆寬為準。

## 技術選型與既有設計

沿用使用者已選定的 daisyUI 5.8.1、暖黃、系統深淺色與字體。新增 range 使用官方 range 元件，dialog／btn／select／card 使用既有元件；聚焦、Tab 循環、Esc 關閉與返回入口。短淡入沿用既有設定並支援 reduced-motion，不為分析或指標增加延遲動畫。

## 資料與驗收

- 本機取樣分析，限制像素工作量；不改寫原圖。完全透明像素略過，半透明像素依 alpha 加權；保留黑白灰，不能自動濾掉大面積背景。
- 代表色是聚類結果，並非逐像素取色或正式 CIS 辨識；相近顏色合併，單色／少色圖可少於選定數量，不複製色塊湊數。
- 約略占比依取樣像素歸屬計算並明確標示；不宣稱照片中擷取的色碼是原品牌精確色碼。
- 開啟時分析目前原圖，換色數重算；無圖停用入口，透明空圖與失敗顯示原因。關閉／換圖／重選色數／視窗關閉使舊工作失效，不將舊結果顯示到新圖。
- 驗收：已知色塊占比、黑白／透明／單色／漸層、3／5／8／12 色、來源隔離、複製成功／失敗、焦點／鍵盤、深淺色／320px、不同筆寬與指標一致、切換與匯入保留本次值、復原與 PNG 匯出。
