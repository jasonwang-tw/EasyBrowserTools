# 本機去背設計與執行紀錄

## 使用者確認（2026-11-18）

1. 商品與人物都要支援。
2. 來源為現有截圖、圖片右鍵擷取，另加本機圖片匯入。
3. 全程本機、不上傳圖片、不需 API Key。
4. 模型按需下載，可刪除；模型權重不放入擴充功能 ZIP。
5. 輸出透明 PNG，可複製與下載。
6. 第一版自動去背、預覽與還原，不新增手動遮罩筆刷。

## 介面與資料

- 沿用使用者已選的 daisyUI、暖黃色、字體及減動效設定。只在現有編輯器補上「匯入圖片」、去背操作與模型管理，不更動其他工具的風格。不另建頁籤或新框架。
- 原圖獨立保留，OCR 持續讀原圖；去背只更換標註畫布的底圖，已加的文字／編號保留。去背結果保留在目前視窗，透明棋盤僅為預覽、不寫入 PNG；還原回原圖。
- 模型僅在使用者明確點擊下載並同意來源後下載。固定版本、大小、SHA-256 校驗後原子存入獨立 IndexedDB，可取消／刪除；不得清除 OCR 模型。圖片不進背景下載通道，不持久保存。
- 匯入本機 PNG／JPEG／WebP，保留透明度；驗證解碼尺寸及像素上限，匯入會開始新的圖片工作並清除上一張標註。OCR 自動辨識保持既有行為。
- 1.8.2 支援 Ctrl+V／Cmd+V 貼上圖片並取代目前文件，與檔案匯入共用驗證／資料清理；成功後清除舊標註、裁切、去背與譯文，無跨圖片復原。文字輸入框與其他模態 dialog 不攔截；只處理 paste 提供的第一張圖片檔、不下載圖片網址、不申請 clipboardRead。
- 去背以獨立 Worker 處理，顯示階段進度、可取消；逾時或錯誤不覆蓋圖片。下載／推論各有鎖定及關閉清理。沿用簡短狀態轉換，不加入長動畫或 Three.js。

## 模型比較與選用方向

| 方案 | 授權／優點 | 代價與目前判斷 |
| --- | --- | --- |
| [BiRefNet Lite](https://github.com/ZhengPeng7/BiRefNet)；[瀏覽器優化 512 ONNX](https://huggingface.co/clevr-tools/birefnet-lite-web) | MIT；通用前景分割；優化版分塊 deformable convolution，降低瀏覽器記憶體峰值 | 101,066,931 bytes（約 101.1 MB）；512 輸入縮放會影響細髮及透明物件。優先實測封裝 WASM，固定下載 revision 與 SHA-256。 |
| [U²-Net／U²-NetP](https://github.com/xuebinqin/U-2-Net) | Apache-2.0；小型版本下載較輕 | 作為輕量候選，不能假設細節效果與 BiRefNet 相同；本輪優先測 BiRefNet。 |
| [IMG.LY background-removal-js](https://github.com/imgly/background-removal-js) | 已提供瀏覽器去背整合 | AGPL-3.0；不引入此套件，使用授權相容的模型及現有 ONNX Runtime。 |

模型比較是技術選型，不替換已確認的 UI Kit。上游效能／品質數字不等同本專案實測。玻璃、細髮、低對比及多主體圖片需核對，不能保證所有圖片自動去背完整。

## 驗收計畫

- 先以正式 Worker 驗證 MV3 CSP、本機模型、產品／人物圖片、alpha 透明與原尺寸；模型資料只放 output 或測試設定檔。
- 再驗證匯入、截圖／右鍵既有入口相容、去背／還原、標註保留、OCR 不受影響、PNG 與剪貼簿透明、下載進度／取消／拒絕／錯誤、深淺色與窄視窗。
- 完成後更新 README、PRIVACY、UI_INVENTORY、VALIDATION 與版本，執行 npm test／check、ZIP 逐檔雜湊。沒有 build／monitor script 時不新增假檢查。這輪不提交或推送。

## 已完成

1.5.0 已依上述規格完成。36 項隔離 Edge 操作與 105 項 Node 測試通過，實際商品／人物去背、透明 PNG 複製／下載、還原／標註、OCR 回歸及模型隔離已驗證。安裝包 17.50 MiB，不含 101.1 MB 去背權重。完整證據與原生授權等未驗證界線統一記於根目錄 VALIDATION.md，後續以該檔為準。
